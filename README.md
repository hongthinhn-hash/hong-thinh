## 🚀 Hướng dẫn đưa website lên GitHub Pages (Miễn phí 100%)

Website được xây dựng theo chuẩn mã nguồn tĩnh (HTML5 / Tailwind CSS / Vanilla JS) với đường dẫn tương đối (`./assets/...`), do đó **hoàn toàn tương thích** và sẵn sàng hoạt động ngay trên **GitHub Pages** mà không cần bất kỳ công đoạn build phức tạp nào.

### Cách 1: Sử dụng Git qua dòng lệnh (Terminal)

1. Mở PowerShell hoặc Terminal trong thư mục này:
   ```bash
   git init
   git add .
   git commit -m "Khoi tao website Hong Thinh - Toi Yeu Cuoc Song"
   ```

2. Tạo một Repository mới trên tài khoản GitHub của bạn (ví dụ đặt tên là `hong-thinh` hoặc `<ten-user-github>.github.io`).

3. Liên kết và đẩy code lên:
   ```bash
   git branch -M main
   git remote add origin https://github.com/<ten-user-github>/<ten-repo>.git
   git push -u origin main
   ```

4. Kích hoạt GitHub Pages:
   - Vào mục **Settings** của Repository trên GitHub.
   - Chọn mục **Pages** (ở cột bên trái).
   - Tại **Build and deployment > Branch**: Chọn nhánh `main` và thư mục `/ (root)`.
   - Bấm **Save**. Sau khoảng 1-2 phút, GitHub sẽ cung cấp link website trực tiếp của bạn (dạng: `https://<ten-user>.github.io/<ten-repo>/`).

---

### Cách 2: Kéo thả trực tiếp trên giao diện Web GitHub

1. Truy cập [github.com](https://github.com) và tạo một **Repository** mới (đặt ở chế độ Public).
2. Nhấn vào nút **Upload files**.
3. Kéo thả file `index.html`, thư mục `assets` và các file liên quan lên GitHub rồi nhấn **Commit changes**.
4. Vào **Settings > Pages > Branch**, chọn `main` và bấm **Save**.
